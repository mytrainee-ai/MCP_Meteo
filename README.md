# Weather AI Agent

Учебный проект на Python 3.14. Агент отвечает на вопросы о погоде по-русски. Модель OpenAI через Responses API выбирает инструмент, а Python вызывает его на удалённом MCP-сервере.

Чат работает в браузере на Streamlit. Агент хранит контекст текущей сессии, поэтому после вопроса о городе можно спросить «А завтра?». [Архитектура](ARCHITECTURE.md) · [Требования](PRD.md)

## Установка и запуск в Windows

Из корня проекта установите зависимости в виртуальное окружение. Первую команду выполните при создании нового окружения.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если локального `.env` ещё нет, создайте его по образцу [.env.example](.env.example). Для реального запроса заполните настройки в `.env`.

- `OPENAI_API_KEY` — ключ выбранного провайдера.
- `OPENAI_BASE_URL` — базовый адрес API провайдера, например `https://api.openai.com/v1`. SDK добавляет к нему путь `/responses`. Провайдер должен поддерживать Responses API с вызовом функций.
- `OPENAI_MODEL` — идентификатор модели у выбранного провайдера.
- `MCP_URL` — адрес погодного MCP-сервера. По умолчанию используется сервер из PRD.

Запустите приложение в PowerShell.

```powershell
.\start.ps1
```

Чат откроется по адресу [http://localhost:8501](http://localhost:8501). Введите, например, «Какая сейчас погода в Москве, Россия?», затем «А завтра?». Кнопка «Очистить чат» сбрасывает переписку и контекст. После изменения `.env` перезапустите приложение. Для остановки нажмите `Ctrl+C` в PowerShell.

Запрос из чата использует настроенного провайдера Responses API и удалённый MCP-сервер. Исходные учебные примеры в `weather_agent.py` и `weather_chain.py` иллюстрируют выбор инструментов моделью и прямые вызовы MCP.

## Лимиты и журнал

Эти параметры можно задать в `.env`. Если их пропустить, приложение использует значения из примера.

- `AGENT_MAX_STEPS=6` — максимум запросов к Responses API для одного сообщения.
- `AGENT_MAX_TOOL_CALLS=10` — максимум попыток вызова MCP-инструментов для одного сообщения.
- `REQUEST_TIMEOUT_SECONDS=30` — общий бюджет времени на запрос, включая открытие и закрытие соединений.
- `DEBUG=false` — включите `DEBUG=true`, чтобы видеть в окне запуска номера шагов, имена вызванных инструментов и типы ошибок. Журнал приложения не пишет ключи или содержимое переписки.

Если ответ MCP превышает 32 КиБ после сериализации, агент получает сообщение об ошибке и может запросить меньший объём данных.

## Тесты без сети

```powershell
.\.venv\Scripts\python.exe -m pip install pytest==9.2.0 pytest-asyncio==1.5.0
.\.venv\Scripts\python.exe -m pytest
```

Pytest собирает unit-тесты из `tests/`, в том числе проверки интерфейса через Streamlit AppTest. Корневые диагностические скрипты исключены из сбора и предназначены для ручного запуска. `test_openai.py` отправляет реальный запрос уже при импорте.
