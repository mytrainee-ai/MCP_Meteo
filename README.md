# Weather AI Agent

Учебный проект на Python 3.14. Агент отвечает на вопросы о погоде по-русски. Модель OpenAI через Responses API выбирает инструмент, а Python вызывает его на удалённом MCP-сервере.

Готово ядро агента с консольным запуском для одного вопроса. Память диалога и браузерный чат на Streamlit предусмотрены следующими этапами. [Архитектура](ARCHITECTURE.md) · [Требования](PRD.md)

## Установка и запуск в Windows

Из корня проекта установите зависимости в виртуальное окружение. Первую команду выполните при создании нового окружения.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если локального `.env` ещё нет, создайте его по образцу [.env.example](.env.example). Для реального запроса заполните настройки в `.env`.

- `OPENAI_API_KEY` — ключ выбранного провайдера.
- `OPENAI_BASE_URL` — базовый адрес API провайдера, например `https://api.openai.com/v1`. SDK добавляет к нему путь `/responses`. Провайдер должен поддерживать Responses API с вызовом функций.
- `OPENAI_MODEL` — идентификатор модели у выбранного провайдера.
- `MCP_URL` — адрес погодного MCP-сервера. По умолчанию используется сервер из PRD.

Запустите консольное приложение и введите вопрос, например «Какая сейчас погода в Москве, Россия?».

```powershell
.\start.ps1
```

Тот же запуск напрямую из корня проекта.

```powershell
.\.venv\Scripts\python.exe -m src.cli
```

Вызов из консоли с вопросом использует OpenAI API и удалённый MCP-сервер. Для учебного разбора исходные примеры находятся в `weather_agent.py` (выбор инструментов моделью) и `weather_chain.py` (прямые вызовы MCP).

## Тесты без сети

```powershell
.\.venv\Scripts\python.exe -m pip install pytest==9.2.0 pytest-asyncio==1.5.0
.\.venv\Scripts\python.exe -m pytest
```

Pytest собирает unit-тесты из `tests/`. Корневые диагностические скрипты исключены из сбора и предназначены для ручного запуска. `test_openai.py` отправляет реальный запрос уже при импорте.
